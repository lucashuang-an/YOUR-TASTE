设计思路

v1 → v2 的转向，全部来自新 50 张的像素与题材，而不是换一种「好看」。

冷中性取代暖纸

新片中性像素最多，蓝其次；平均冷暖 −1.5。阴天纸底比 v1 奶油色更贴画面，也避免整站发黄。

赤陶降为稀疏强调

织物、红船、寺院仍在，但已不是主色族。交互仍用赤陶，面积必须比 v1 更小。

金退出主色

金佛与木构存在，只够做点缀 token，不能和赤陶抢第二主色。

更空的版式

大片山海、阴天、海灰信息量低；图距拉到 8–12vh，禁止等宽卡片阵。

明暗双极

L 从 26 到 152：既要夜景近黑，也要高调阴天。token 必须同时支持深底块与浅纸底。

字体约束不变

中文宋体+苹方，英文 Georgia / Segoe / Consolas 封顶三种，等宽不进正文。
