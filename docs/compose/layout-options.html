四种排版模板 · 实物预览

用同一批精选照片试排。当前站点是偏满的编辑流；下面四种都更强调留白与呼吸。看完选一个编号即可。

A 美术馆疏墙 B 呼吸感非对称 C 全幅 + 停顿 D 索引展开
TEMPLATE A

美术馆疏墙

一屏一图、边距极大、图说极小。最安静，50 张页面会很长，适合当「精选墙」而不是快速浏览。

参考方向： michaelkenna.com · 极简风景 / 大量留白
TEMPLATE B

呼吸感非对称编辑流

章节间距大；单行 1 图或左右错位；故意留空列，图宽不一。推荐：仍有叙事节奏，又不塞满。

参考方向： aperture.org · 编辑式图文； jimmychin.com · 大图与节奏

TEMPLATE C

全幅章节 + 文字停顿

每章先整屏大图，中间用纯文字章节语停一停，再竖向放图。更像摄影 essay，适合章节感强的 6 组。

参考方向： Salgado / Instituto · 纪实长卷； magnumphotos.com · 长图叙事
